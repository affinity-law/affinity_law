01
准备时间序列
NPY 支持 [时间点] 或 [时间点, 变量] 的数值数组。CSV 可有表头与首列时间戳；不支持缺失值、无穷值和非数值变量。网页不会悄悄插值或重排时间。
02
了解运行模式
项目示例使用已选定的 L 架构和历史测试记录。新数据通过 L 生成候选并按验证集 RMSE 选出架构。
03
查看推荐依据
只采用 S/A 级规律，排除反偏好角，再按等级和 lift_ci_lo 排序。A/B/C 未命中使用发现集频率默认，E 未命中使用 Single Block。D 逆变换从 A 自动推导。
04
一次开始，自动完成
在首页选择预测步数与是否调参，点击“开始建模”。工作台会自动衔接特征计算、模块选择、训练与评估，完成后打开结果页。
05
复用模型与报告
下载完整 .py 文件与包含特征、命中规则、架构和配置的 JSON 报告。源码需要项目原有 PyTorch 环境；默认源码不包含权重，不代表已完成训练。

本地运行状态
在完整项目的根目录，激活已安装依赖的 Python 环境后运行：
python -B 4html/start.py
浏览器会自动打开本机工作台。保持启动终端运行，按 Ctrl+C 停止。单独双击 HTML 可以体验示例，实际计算需要此本地进程。
